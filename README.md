# Civilization Theatre

Public source-only development baseline for the Civilization Theatre research project.

## Baseline

This repository imports the exact 158 members listed by the 1446 generation manifest. The original manifest is preserved at `baseline/generation-manifest.1446.original.json` for provenance. Its recorded state is `preparation_only=true`, `tests_executed=false`, and `release_accepted=false`; this repository does not claim product, isolation, model, browser, or release acceptance.

Historical evidence, databases, credentials, private worlds, logs, runtime candidates, and delivery artifacts remain outside this repository.
